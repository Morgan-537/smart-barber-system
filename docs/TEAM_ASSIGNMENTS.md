feature branch → develop → main

Only reviewed and tested code will be merged into `develop`.

# Team Rules

- Pull from `develop` before starting work.
- Push only to your assigned feature branch.
- Create a Pull Request to `develop` after completing your feature.
- Do not merge your own Pull Request.
- Inform the team before making database changes.
